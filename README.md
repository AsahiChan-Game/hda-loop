# HDA Loop

围绕已认可的美术基准和具体缺口迭代：固定正式工程，完成优秀代表样本，再扩展有意义的变体；研究规则接回主线，修改后检查是否退步。制作并交付 Houdini 生成器及 UE 产物。支持植物、道具、建筑与完整室内、城市；按当前任务确定范围。

按 [平台与资产标准](references/asset-standards.md) 选择手游、PC/主机、高端实时或影视目标，再按 [美术方向](references/art-direction.md) 判断写实、风格化、手绘、卡通等造型与表面要求。研究来源见 [官方资料索引](references/standards-sources.md)。不使用统一面数、贴图尺寸或美术分数作为所有资产的完成线。

入口：[SKILL.md](SKILL.md)。显示名 **HDA Loop**，调用 `$hda-loop`；与原版 `dream-loop` 独立。

流程分两步：第一步在 Houdini 中完成 HDA 制作与自检，交付 A/B/C 三张变体图并保存预设，等待用户看图确认满意；确认后第二步才开始制作 UE 集成内容，以同一个 HDA 和相同预设在 UE 中复现 A/B/C，完成验收并交付三张对应 UE 图片。完整流程共六张独立图片。用户未确认之前不开始 UE 实施；案例帮助归纳必要条件，不固定风格或技术路线。

例如：“用 $hda-loop 做一个房屋生成器，先检查优秀房屋需要哪些构件和关系、当前素材缺什么，再完成代表样本并验证参数变化。”

保留原 dream-loop 作者 Anshu Chimala 的 MIT 许可。本技能文件经过检查不代表 HDA、UE 或视觉效果已经通过实测。

连续任务使用 [简短工作记录](references/iteration-state.md)。中途研究图与正式验收分开；仍明显偏离目标的样机继续修复，不以技术检查通过代替美术自检完成。
